# Release notes — 2026-10-31

This release covers work since the [October 27 release](RELEASE_2026-10-27.md).

## New

- **Sharing switch.** Owners can toggle sharing on or off for shared conversations without losing keys or state (migration 064).
- **Guest approval and limits.** Configurable per-guest message limits on guest links, and owner approval workflow for guest admissions (migration 065).
- **Guest link requests and account requests.** Guest links support direct join and request modes, with optional request notes and signed-in account requests (migration 066).
- **Auth event pruning timer.** Automatic pruning script and systemd timer for retained auth audit events.

## Improved

- **Mobile phone layout:** Sideways/landscape phone view constraints preventing top bar and council chamber from consuming screen height, giving full room to chat.
- **Activity cards and news feed:** Mobile message bubble overflow prevention ensuring long context paths or unbroken tokens do not push or clip summary text off screen.
- **Unread badge:** Unread counts clear immediately upon opening a conversation.
- **Model picker ordering:** Preserves provider-reported catalog ordering instead of sorting alphabetically.

## Upgrade and rollback

Back up your database, configuration, and current Git commit. Run `npm ci`, then `npm run migrate`, and restart. Migrations `064`–`066` are additive.
