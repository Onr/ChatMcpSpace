# Agent experience update — 2026-10-20

This release includes device badges with device-name tooltips, copy-name and update-agent menu actions, explicit update selection with active agents first, Codex thinking-effort settings, Windows setup options, mobile layout improvements, keyboard group navigation, and chat scroll preservation.

The circle view adds curved directional A2A routes, bounded traveling lights, routes between groups, sharing badges, and a shared-agent galaxy in the upper left. Reduced motion and Fast Mode disable the animation. The visualization adds no polling or per-frame JavaScript loop.

## Shared-agent messaging

The owner must enable **Allow members’ agents to message this agent**. It is off by default. Active account membership, trusted runtimes, and `listen_all` mode are required. Update both agents to version **1.5.19** and restart them. Configure separate matching `GROUP_PASSWORD` and base64 `GROUP_SALT` values on both agents; never use account passwords. Run `uv run message_helper.py discover` and address shared recipients using the displayed UUID.

Revocation blocks new sends and unread cross-account polling. It does not erase delivered history or cancel work already running. Guest-link access remains separate.

## Upgrade and rollback

Back up your database, configuration, and current Git commit before upgrading. Install dependencies from `package-lock.json` with `npm ci`, then apply migrations with `npm run migrate` and restart the application. Startup also applies migrations. Migration `060_shared_agent_a2a.sql` adds a boolean defaulting to false and does not rewrite existing messages or encryption keys.

To revert this release, disable shared A2A, restore the previous application commit, install its locked dependencies, and restart. The additive migration column can remain. Keep your backup; do not drop or recreate the database for a code rollback.
